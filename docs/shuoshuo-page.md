# 说说页面模板

`template-shuoshuo.php` 为普通 WordPress 页面增加「说说时间轴」模板，读取主题已有的 `shuoshuo` 内容，不需要搬迁已有说说。

## 使用

1. 将此文件部署到当前启用的 Sakurairo 主题根目录。
2. 在 WordPress 后台新建页面，或编辑一个已有页面。
3. 在页面模板中选择「说说时间轴」，填写标题并发布。
4. 页面正文可填写介绍；说说在介绍下方显示。
5. 在主题现有的「说说」后台发布内容。时间轴按发布时间倒序，每页 20 条。

建议页面使用 `moments` 等别名，避免与已有 `shuoshuo` 自定义内容归档路径冲突。模板也支持设为静态首页。

## 行为

- 使用独立参数 `ss_page` 分页，不改变普通页面的主查询或内容分页。
- 显示作者、时间、月份分组及经过 WordPress 内容过滤器处理的正文和媒体。
- 仅显示已发布且无密码的说说；草稿、私密、定时及密码保护内容不公开。
- 页面本身有密码时，解锁前只显示密码表单，不显示时间轴。
- 分页使用普通链接，无 JavaScript 也可以访问；保留主题现有 PJAX 导航。
- 样式随模板内容加载，支持主题的 `body.dark` 暗色模式。
- 不修改既有说说归档、后台、文章、主题配置或数据库。

## 部署与回滚

发布前确认线上 WordPress/PHP 版本、启用主题路径及 `shuoshuo` 内容类型已注册。不同 Sakurairo 版本需先确认模板调用的页面模板片段仍存在。

上传前备份同名文件（如果存在）。仅上传 `template-shuoshuo.php`，无需覆盖完整主题或修改主题版本号。上传后用服务器 PHP 执行 `php -l`，检查后台识别、页面内容及分页。

回滚时将页面模板改回默认模板，然后恢复备份文件或移除本次新增文件。无需删除说说或恢复数据库。页面模板的分配属于独立操作，部署记录应保存原模板值。

## 已验证

在 WordPress 6.8 / PHP 8.3 的独立 Playground 中确认模板自动注册并成功渲染：

- 45 条已发布说说按 20 / 20 / 5 分页，顺序正确且无重复遗漏。
- 草稿、私密、定时和带密码的说说不会出现在时间轴中。
- 页面本身有密码时，未解锁不会显示说说。
- 静态首页、越界页码、负数和数组形式页码参数正常处理。
- 浏览器实际点击分页（包含 PJAX）、390px 手机布局及明暗模式正常。
